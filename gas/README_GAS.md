# Googleドライブ画像OCR・自動誤答解析システム (GAS) セットアップ手順

スマホで撮影した「間違えたプリントや答案」の写真をGoogleドライブに入れるだけで、
最新の **Gemini 3.8 Flash**（または **Gemini 4 Argon**）が自動解析し、スプレッドシートの `weakness_db` に登録される仕組みの導入手順です。

---

## 1. 準備するもの
1. **Googleスプレッドシート**（ID: `1ZFTjAOHDhlk8S3e35gEwxy-LXfupl7x_86s4lqKWFEw`）
2. **Gemini API Key**（Google AI Studioで発行した無料キー）

---

## 2. セットアップ手順（約3分）

### ステップ①：Apps Script エディタを開く
1. 対象の Google スプレッドシートを開きます。
2. 上部メニューの **「拡張機能」>「Apps Script」** をクリックします。

### ステップ②：コードを貼り付ける
1. エディタに表示されている初期コードをすべて削除します。
2. `gas/AutoOCR_WeaknessDB.js` の内容をすべてコピーして貼り付けます。
3. 上部のフロッピーディスクアイコン（保存）をクリックして保存します。

### ステップ③：APIキーを安全に登録する（スクリプトプロパティ）
コード内に直接APIキーを書かずに、安全に登録します：
1. Apps Script 画面の左端にある **「プロジェクトの設定（歯車アイコン ⚙️）」** をクリックします。
2. 画面下部の **「スクリプト プロパティ」>「スクリプト プロパティを追加」** をクリックします。
   - **プロパティ**: `GEMINI_API_KEY`
   - **値**: あなたのGemini APIキー
3. **「スクリプト プロパティを保存」** をクリックします。

### ステップ④：テスト実行＆権限承認
1. 左メニューの **「エディタ（＜＞アイコン）」** に戻ります。
2. 上部の実行関数が `processNewStudyImages` になっていることを確認し、**「実行」** をクリックします。
3. 初回実行時に「承認が必要です」というダイアログが表示されます：
   - 「権限を確認」をクリック
   - 自分のGoogleアカウントを選択
   - 「詳細」をクリック ＞ 「安全ではないページに移動」をクリック
   - 「許可」をクリック

### ステップ⑤：自動化トリガーの設定（放置で自動解析）
1. 左メニューの **「トリガー（時計アイコン ⏰）」** をクリックします。
2. 右下の **「トリガーを追加」** をクリックします：
   - 実行する関数: `processNewStudyImages`
   - イベントのソース: **「時間主導型」**
   - 時間ベースのトリガーのタイプ: **「分ベースのタイマー」**
   - 時間の間隔: **「10分ごと」**（または15分ごと）
3. **「保存」** をクリックします。

---

## 3. 使い方
1. Googleドライブのマイドライブ内に **`Study_Uploads`** というフォルダが自動生成されます。
2. スマホのGoogleドライブアプリから、間違えた問題やノートの写真をこの `Study_Uploads` フォルダにアップロードします。
3. 10分以内に Gemini 3.8 Flash が自動解析し、スプレッドシートの `weakness_db` に新しい問題が自動追加されます！
4. 解析が終わった画像は自動的に `Study_Uploads_Processed` フォルダに移動します。
