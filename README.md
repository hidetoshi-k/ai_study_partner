# AI学習パートナー システム仕様書

## 1. 概要
松江北高校理数科（高1）から医学部医学科を目指す受講生向けの完全自走型AI学習伴走システム。

## 2. システム構成
- **フロントエンド:** Streamlit (Python) - M2 Mac上で開発し Streamlit Cloud にデプロイ
- **データベース:** Googleスプレッドシート (ID: 1ZFTjAOHDhlk8S3e35gEwxy-LXfupl7x_86s4lqKWFEw)
  - `target_roadmap`: テスト・模試目標
  - `weakness_db`: 弱点・誤答分析 (忘却曲線管理)
  - `study_logs`: 日々の学習実績・EXP
- **バックエンド/自動化:** Google Apps Script (GAS) + Gemini 3.6 Flash API (ドライブの画像OCR・誤答自動解析)
- **知識検索基盤:** NotebookLM (学校プリント・Focus Gold等の解説PDF)

## 3. アプリの主要タブ機能
1. ☕ 朝の作戦会議（条件指定・AIプラン3案提示・動的リアルタイム再計算）
2. 🏠 本日のダッシュボード（朝礼メッセージ・合格EXPバー・タスク一覧）
3. 🔄 弱点克服＆復習ドリル（エビングハウス忘却曲線再出題・Python自己検算・ファインマン解法解説）
4. 📈 全体ロードマップ（カウントダウン・バーンダウンチャート）
5. 💬 24時間質問部屋（ソクラテス式ヒント対話）
