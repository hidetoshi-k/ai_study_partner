# AI学習パートナー システム仕様書

## 1. 概要
松江北高校理数科（高1）から国公立大学医学部医学科を目指す受講生向けの完全自走型AI学習伴走システム。

## 2. システム構成
- **フロントエンド:** Streamlit (Python) - M2 Mac上で開発し Streamlit Cloud にデプロイ
- **ローカルデータベース:** SQLite3 (`ai_study_partner.db`) による全操作リアルタイム自動保存
  - `study_logs`: 日々の学習実績・EXP・達成状態
  - `weakness_db`: 弱点・誤答分析 (エビングハウス忘却曲線サイクル管理)
  - `target_roadmap`: 入試・模試目標・科目別進捗
  - `chat_history`: 24時間質問部屋のAI対話履歴
  - `app_meta`: 連続学習日数（ストリーク）・振り返りメモ
  - `exam_records`: 模試・定期テスト成績（数学・英語・理科・総合偏差値・順位）
  - `unit_progress`: Focus Gold ＆ 理科 単元別マスター進捗
- **クラウド連携（任意）:** Googleスプレッドシート (ID: `1ZFTjAOHDhlk8S3e35gEwxy-LXfupl7x_86s4lqKWFEw`)
- **AI頭脳:** Gemini 3.6 Flash API（Google AI Plus対応、3.5 Flash-Lite / 3.1 Pro / 4 Argon 切替可能）
- **知識検索基盤:** NotebookLM (松江北高プリント・Focus Gold等の解説PDF)

## 3. アプリの主要5大タブ機能
1. **🎯 今日の作戦会議（Today's Strategy）**
   - 目標学習時間・希望スタイル・疲労度コンディションに応じた科目配分・予想EXPの動的リアルタイム再計算
   - 3大プラン（プランA: 王道バランス、プランB: 数・理 突破、プランC: 弱点総ざらい）提示
   - 放課後・帰宅後の生活リズムに最適化（平日3.5h初期値、休日切り替え）
   - Geminiオーダーメイドプラン考案ボタン
   - プラン確定で本日のタスクをSQLiteへ即時反映

2. **🏠 本日のダッシュボード**
   - AI朝礼メッセージ
   - 医学部合格EXPメーター（累計EXP、レベル、本日の進捗）
   - タスクチェックリスト（チェックを入れると即座に自動保存）
   - **🌙 夜の振り返り（Daily Check-out）**: 1日の気づきメモ入力、ソクラテス先生からのAI終礼メッセージ、連続学習記録ストリーク更新（+1日）

3. **🔄 弱点克服＆復習ドリル**
   - **📸 スマホ撮影OCR即時登録**: カメラ撮影/アルバム写真からGemini 3.6 Flashが誤答原因と着眼点ヒントを自動解析・DB登録
   - **エビングハウス忘却曲線サイクル**: 🟢完璧自力クリア(+120EXP) / 🟡ギリギリ・ヒント見た(+60EXP) / 🔴解けなかった(明日再出題) による復習サイクル自動更新
   - **NotebookLMワンクリック検索連携**: Focus Gold類題・学校プリントの解説PDFへ瞬時にアクセス
   - **🧮 Python自己検算ツール**: 2次関数の軸・頂点・最大最小グラフ描画検算、モル計算・数値計算の厳密検証
   - **🧠 ファインマンモード**: 専門用語を使わない本質解説のアウトプット × Geminiリアルタイム採点
   - **🖨️ 週末弱点総復習テスト（A4印刷・まとめ出力モード）**: 忘却曲線DBの弱点問題を一括抽出し、A4テスト用紙を自動生成。ワンクリックブラウザ印刷（Cmd+P）やMarkdownダウンロードに対応

4. **📈 全体ロードマップ＆進捗分析**
   - 入試・駿台模試・期末テストへのカウントダウン
   - 70時間スプリント バーンダウンチャート（理想ペース線 vs 実績推移）
   - 科目別・合格目標到達度プログレス
   - **📊 模試・定期テスト成績管理＆医学部合格ギャップ分析**: 偏差値推移グラフ、医学部ボーダー（偏差値68.0）対比、校内順位・成果メモ追跡、成績登録フォーム
   - **📚 Focus Gold ＆ 理科 単元別マスター進捗マップ**: 数学I・A、先取り数学II・B、物理基礎、化学基礎の全単元チェックリスト（未着手/学習中/一通り完了/Focus Goldマスター）

5. **💬 24時間質問部屋**
   - ソクラテス式AIメンター対話（安易に答えを教えず思考を深める発問を提供）
   - 会話履歴のSQLite自動保存・復元
